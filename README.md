# Energy Software Lab

**Java Software Development | Software Engineering | Energy Systems | Mathematical Modelling**

Energy Software Lab is an independent software engineering portfolio focused on designing, developing and testing software applications within the energy sector.

The portfolio consists of a growing collection of Java projects exploring different energy technologies and systems. Each project combines software engineering principles with mathematical modelling and domain-specific knowledge to investigate an energy-related problem.

The primary objective is to develop and demonstrate practical software development skills, including object-oriented programming, software architecture, testing, data processing and technical documentation, while building a deeper understanding of energy systems.

## Development Approach

Each project follows a structured software development process:

1. **Problem Definition** — Identify the engineering problem, objectives and scope.
2. **Mathematical Modelling** — Establish governing equations, physical constraints and assumptions.
3. **Software Design** — Define system requirements, architecture and component responsibilities.
4. **Implementation** — Translate the mathematical model into Java.
5. **Verification & Validation** — Test computational correctness and evaluate physical plausibility.
6. **Experiments & Analysis** — Investigate system behaviour and interpret results.
7. **Documentation** — Present the methodology, findings and limitations in a technical report.

The emphasis is on readable, maintainable and testable software, supported by physically meaningful models, reproducible results and transparent engineering assumptions.

## Current Project — Battery Energy Storage

The first project focuses on developing a discrete-time battery energy storage simulator in Java.

The model considers charging and discharging efficiencies, energy capacity, state-of-charge limits and power constraints. A rule-based controller determines battery operation based on electricity prices.

**Research question:**

*How does battery storage efficiency affect the economic value of rule-based electricity-price arbitrage?*

The mathematical model and initial software architecture have been designed. Java implementation, verification and experimental analysis are the next stages.
